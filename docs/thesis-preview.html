Design thesis — genjutsu:paint

IPO Risk Decoder — Vercel/Linear-disciplined dashboard

Portfolio-first redesign: near-black monochrome ground, one sharp signal-blue accent, IBM Plex Sans/Mono throughout, hairline-bordered sharp-edged panels. Every token below feeds the real implementation — nothing here is decorative.

Visual thesis

Statement

A near-black monochrome dashboard with one sharp signal-blue accent reserved for action and focus — IBM Plex Sans/Mono for a disciplined, engineered voice, dense-but-organized spacing that opens up between sections and tightens within lists, and sharp hairline-bordered panels instead of soft shadowed cards.

Color
Near-black ground, one accent (#4C6FFF) reserved for interactive/focus states only; severity keeps its own distinct 5-color scale so state and brand never compete.
Type
IBM Plex Sans for UI/headings, IBM Plex Mono for every number — scores, percentages, counts. Tight letter-spacing on display sizes.
Spacing
Generous gaps between sections (32–64px), disciplined tight spacing within lists/tables (8–12px) — Linear's restraint, not uniform airiness.
Components
Sharp 4px radii max, 1px hairline borders instead of drop shadows, severity encoded as a color stripe + mono score, not prose alone.

Interaction thesis

Statement

Fast, dry, engineered motion — 140–180ms ease-out on every hover and state change, no scale-on-hover, no bounce or elastic easing, no scroll-triggered reveals or parallax. This is a working instrument, not a marketing page.

Timing
140ms for hover/color transitions, 180ms for positional moves. Nothing slower than 200ms.
Hover
Background/border shift only — no transform scale, no glow.
Scroll
None. Content renders immediately; this is scanned data, not a story.
Forbidden
Bounce, elastic, spring overshoot, scale-on-hover, parallax, decorative scroll reveals.
